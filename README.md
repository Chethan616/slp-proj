# Vox — Voice-Enabled Chatbot (Speech Recognition + Deep Learning)

A web chatbot you talk to. Speech is transcribed by **Whisper**, the transcript is
classified into one of **41 intents** by a **fine-tuned DistilBERT** model, and a
response is generated from the predicted intent. Both the recognised speech and
the reply are shown in the interface, along with the intent and its confidence.

## Pipeline

```
microphone ──► MediaRecorder (webm/opus)
                     │
                     ▼  POST /api/voice
        faster-whisper base.en (int8, CTranslate2)
                     │  recognised text
                     ▼
        DistilBERT intent classifier (41-way softmax)
                     │  intent + confidence
                     ▼
        template response  ──►  displayed + optionally spoken
```

## Dataset

**CLINC150** (Larson et al., EMNLP 2019) — a benchmark built specifically for
intent classification *with* an explicit out-of-scope class. This project uses a
40-intent subset spanning eight domains (small talk, utility, travel, auto and
commute, banking, home, work, kitchen and dining) plus the `oos` class, giving
4,250 training / 900 validation / 1,500 test utterances.

## Running locally

```bash
pip install -r requirements-train.txt

python train/prepare_data.py      # build the CLINC150 subset
python train/train_baselines.py   # three reference models
python train/train_distilbert.py  # the deployed model -> app/model/
python train/evaluate.py          # figures + results/summary.md
python train/eval_voice.py        # end-to-end speech evaluation (WER)

cd app && uvicorn main:app --port 7860   # http://localhost:7860
```

Or with Docker, exactly as the Space runs it:

```bash
docker build -t vox . && docker run -p 7860:7860 vox
```

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/` | chat interface |
| POST | `/api/voice` | multipart audio → transcript + intent + reply |
| POST | `/api/transcribe` | multipart audio → transcript only |
| POST | `/api/chat` | `{"text": "..."}` → intent + reply |
| GET | `/api/info` | model metadata and the intent list |
| GET | `/health` | liveness probe |
