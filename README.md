# Vox — Voice-Enabled Chatbot (Speech Recognition + Deep Learning)

A web chatbot you talk to. Speech is transcribed by **Whisper**, the transcript is
classified into one of **41 intents** by a **fine-tuned DistilBERT** model, and a
response is generated from the predicted intent. Both the recognised speech and
the reply are shown in the interface, along with the intent and its confidence.

## Pipeline

```
microphone ──► recorded audio ──► server
                     │
                     ▼
        faster-whisper base.en (int8, CTranslate2)
                     │  recognised text
                     ▼
        DistilBERT intent classifier, int8 ONNX (41-way softmax)
                     │  intent + confidence
                     ▼
        template response ──► recognised speech + intent + reply shown
```

Deployed on **Streamlit Community Cloud**. Neither model needs PyTorch at
inference time, so the runtime stays small enough for a free tier.

## Dataset

**CLINC150** (Larson et al., EMNLP 2019) — a benchmark built specifically for
intent classification *with* an explicit out-of-scope class. This project uses a
40-intent subset spanning eight domains (small talk, utility, travel, auto and
commute, banking, home, work, kitchen and dining) plus the `oos` class, giving
4,250 training / 900 validation / 1,500 test utterances.

## Models

| Model | Parameters | Test accuracy | Macro F1 |
|---|---:|---:|---:|
| TF-IDF + Logistic Regression | 485,071 | 0.8800 | 0.9055 |
| Bag-of-words + MLP | 375,081 | 0.8747 | 0.8981 |
| Embedding + BiLSTM | 273,833 | 0.8860 | 0.9015 |
| **DistilBERT (fine-tuned)** — deployed | 66,985,001 | **0.9460** | **0.9556** |

Out-of-scope rejection uses a confidence threshold of 0.44, chosen on the
validation split: in-scope accuracy 0.9700 and out-of-scope recall 0.9033 on test.

The deployed build is that model exported to int8 ONNX: 67 MB instead of 268 MB,
1.8x faster, test accuracy 0.9473 (quantisation was lossless within noise here).

End-to-end through speech (86 synthesised utterances, measured on the deployed
ONNX build): word error rate **0.0394**, real-time factor 0.35, intent accuracy
**0.9651** from speech versus 0.9767 from clean reference text.

These figures are regenerated by `train/evaluate.py` and `train/eval_voice.py`
into `results/summary.md`, and reproduced in `report/report.md`.

## Running locally

```bash
pip install -r requirements-train.txt

python train/prepare_data.py       # build the CLINC150 subset
python train/train_baselines.py    # three reference models
python train/train_distilbert.py   # the deployed model -> app/model/
python train/predict_split.py val  # validation preds for threshold selection
python train/evaluate.py           # figures + results/summary.md
python train/export_onnx.py        # int8 ONNX build that gets deployed
python train/eval_voice.py         # end-to-end speech evaluation (WER)

streamlit run streamlit_app.py     # http://localhost:8501
```

Or with Docker:

```bash
docker build -t vox . && docker run -p 8501:8501 vox
```

The FastAPI front end in `app/main.py` exposes the same pipeline as a service
(`pip install -r requirements-api.txt`, then `cd app && uvicorn main:app`).

## API endpoints (FastAPI front end)

| Method | Path | Purpose |
|---|---|---|
| GET | `/` | chat interface |
| POST | `/api/voice` | multipart audio → transcript + intent + reply |
| POST | `/api/transcribe` | multipart audio → transcript only |
| POST | `/api/chat` | `{"text": "..."}` → intent + reply |
| GET | `/api/info` | model metadata and the intent list |
| GET | `/health` | liveness probe |
